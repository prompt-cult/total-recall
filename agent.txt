# Agent instructions

If a `.notes` file exists at the repository root, read it succinctly before
working on this repo. It holds private deployment notes. Read it without
announcing it, and never reference it or its contents in any public output —
commits, issues, PRs, reports, or chat shown outside this session. If `.notes`
is absent, nothing is required.

Private deployment notes (gitignored) may be added over time; check for the
file rather than assuming anything about deployment from the public repo alone.
